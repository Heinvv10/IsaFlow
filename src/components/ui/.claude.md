# components/ui/ (the kit)

## Purpose
The shared controls and page furniture every screen is built from: `Button`, `Input`, `Select`, `DateField`, `MoneyField`, `PageHeader`, `Breadcrumb`, `Drawer`, `StatusPill` and friends. Everything is drawn from theme tokens, so it reads in both themes.

## Caller contract
- Import from `@/components/ui`. A form control takes its label through the kit (`no-raw-form-input` and `no-unnamed-control` refuse a raw one).
- `PageHeader` is the page header. Never draw a dark gradient banner: `tests/unit/ci/themeContrastBanner.test.ts` refuses one, and nothing remaps a dark title on it in the light theme any more. A back link is a `breadcrumb` whose last item is the current page. Pass `className="mb-0"` when the content brings its own padding.

## Main signatures
- `PageHeader({ icon, title, subtitle?, actions?, breadcrumb?, backLink?, chipColor?, className? })`: `title` is a string, and the h1; the h1 truncates and carries `title=` only while it is clipped.

## Business rules
- **Label case (wave 3 spec, decision 8; applied in wave 4).** Field labels are sentence case in the kit's `text-sm font-medium`. Uppercase is for eyebrows and table headers only. New code follows this now; the 18 files still on `uppercase tracking-wider mb-1.5` convert in wave 4: `git grep -l "uppercase tracking-wider mb-1.5'" -- pages src`.
- **IDs use `font-id`** (`styles/globals.css`): the app face with tabular figures and a slashed zero, for invoice, journal, employee and account numbers. `font-mono` is for code alone: `eslint/font-mono-allowlist.json` lists the files still using it and only shrinks. After converting a file, run `bun scripts/ci/check-font-mono-allowlist.ts --write` and regenerate rather than hand-merge the list on a conflict.
- **Counts and dates use `tabular-nums`, not `font-id`.** `font-id` is for identifiers, where the slashed zero tells 0 from O. The figures faces (`public/fonts/figures`) are Plex Sans cut to the digits plus the `zero` feature; re-cut them with `scripts/fonts/cut-figures.sh` (`--no-zero [outdir]` rebuilds the pre-slashed-zero cut, which `o3-banner-titles.spec.ts` must fail against, at weights 400, 500 and 600). Needs `pyftsubset` (fonttools + brotli).
