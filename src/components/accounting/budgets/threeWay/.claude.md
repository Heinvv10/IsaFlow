# Three-way budget UI (`src/components/accounting/budgets/threeWay/`)

Budgets P6 PR D, spec `docs/plans/budgets/P6-three-way-spec.md` §8, §10, **§13 overrides**. Page `pages/accounting/budgets/three-way.tsx` (`/accounting/budgets/three-way?version_id=`), `FeatureGate feature="budgets_three_way"` with a neutral fallback (never the upgrade prompt). API contract: `src/modules/accounting/services/budgets/threeWay/.claude.md`.

## Shape
- Data: `threeWayClient.ts` (`fetchThreeWay`, `fetchAssumptions`, `saveAssumptionsDoc`, `fetchCompare`, `fetchLiabilityAccounts`, `fetchLoans`; every call returns an `ApiResult`, nothing throws on a 4xx) → `useThreeWay.ts` (years via the workspace's `useBudgetYears`, the year's versions, `pickVersion`: query id → primary → first) and `useAssumptionsForm.ts`.
- Body `ThreeWayPage.tsx`: `ThreeWayHeader` (switcher, opening chip, Balances chip, `warningText`), `RunwayChart` (`runwayOption.ts`), tabs Balance sheet / Cash flow (`ThreeWayGrid` over `threeWayRows.ts`), Assumptions (`AssumptionsPanel` + `AssumptionFields` + `AssumptionLists`, model `assumptionsModel.ts`), Compare (`CompareTab`, `compareModel.ts`).

## Rules
- Money on the wire is CENTS; the grids show whole rands (`formatStatementFigure`), the check row cents. Subtotals are the engine's figures, never re-added (`threeWayRows`); lines follow the engine's sectioning (VAT control an asset when debit, else a liability).
- `ThreeWayGrid` and not `StatementGrid`: the latter is Actual + comparators and cannot take a column per month. Only the table scrolls sideways; the label column is sticky.
- Balances chip: red when ANY check ≠ 0 (opening or a month), or the server's `checks.balanced` is false. Opening chip amber when provisional; its title shows posted equity vs derived RE.
- Save sends the row token as read (`stored.updatedAt`, null when none). 409 STALE keeps the edits and shows a reload prompt; Reload re-reads (new token, their figures). Locked (status, or a 409 LOCKED on save) = read-only. An edit makes a field `manual`; "Use derived" restores the derive `Prov`.
- A scenario over a resolvable base that stores overrides (or nothing) saves OVERRIDES (`buildSaveDoc`): stored overrides + each changed Prov/list, whole. Otherwise the full document.
- Compare: Δ and `favourable` are the server's; ink only via `ibcs.varianceColor` (`deltaColour`), Δ = 0 neutral, Δ% "—" when the first is 0. Max 3 versions (`MAX_RUNWAY_SERIES`).
- Chart text through `escapeHtml`; the negative-month shading is `varianceColor(false)`.
- Nav: the link lives in "Management Accounting" (`navSections/accounting.ts`) and "Management" (`accountants.ts`), hidden by `stripFlagNav` (`navSections/flagNav.ts`) unless `useNavFlags()` has the flag; the versions bar shows "Three-way" the same way.
