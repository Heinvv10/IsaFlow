# components/accounting/packs/

## Purpose
Renders a `PackDocument` (from `services/packs/packDocument.ts`) as React — both the interactive preview and the `?print=1` page the PDF pipeline photographs. No figures are computed here; the component tree only lays out what the document model already holds.

## Caller contract
`pages/accounting/reports/report-packs.tsx` is a dispatcher: `isPrintRender(router)` decides between the interactive screen and `PackPrintPage`. The print page renders WITHOUT `AppLayout` and fetches exactly the two paths `packPrintApiPaths` authorises.

## Main signatures
- `PackPrintPage({ packType, from, to })` — the whole of `?print=1`
- `PackPrintView({ document })` · `PackSectionView` · `PackCover` · `PackToc` · `PackChart`
- `usePackPrintData(packType, from, to)` — the print page's two fetches
- `usePrintMode(enabled)` · `usePrintReady(dataReady, expectedCharts)` · `countCharts(sections)`
- `formatPackKv(item): string`

## Business rules
- **The PAGE owns print mode, not the renderer.** `usePrintMode` adds `print-mode` to `<html>` and removes `.dark` in a LAYOUT effect: `ThemeContext` defaults to dark and sets the class in a passive mount effect, so a child that merely removes it is overwritten a frame later and the PDF prints white on white. The Gotenberg transport cannot run a script on our behalf, which is why this cannot live in the renderer.
- **The readiness gate has no timeout on purpose.** `[data-print-ready="true"]` is set only when the data has loaded AND every chart has drawn an `<svg>`. A pack missing a chart is a document sent to a client with a hole in it; a hard render timeout is the loud, diagnosable failure we want instead.
- A margin with no meaning renders through `marginKvItem`/`formatPackKv`, never as `0.0%`.
- `_app.tsx` gates `AuthProvider`, `CompanyProvider` and the analytics tracker off a print render — see `src/lib/pdf/.claude.md` for what each of those fetches costs mid-render. The gate is scoped to this page's path, so another page's `?print=1` is unaffected.
- The dispatcher must decide the branch BEFORE `router.isReady`: on a page with no `getServerSideProps`, `router.query` is `{}` on the first client pass, and one mistaken "not a print render" is enough for a provider's mount effect to fire.
