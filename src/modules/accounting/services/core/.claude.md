# Core service group

Cross-cutting infrastructure services: company management, user access, audit trail, multi-currency, data migration, Sage import/sync, AI categorisation, OCR, smart categorisation, email/notification, payment gateway (PayFast), webhooks, job queue, document storage, and shared PDF helpers. This directory is a catch-all for services that don't belong to a single accounting module.

## Multi-tenant rules

Most services accept `companyId` as first argument and scope all queries to it. **Exception**: `companyService.listCompanies()` is un-scoped (admin use only — do not expose via tenant API routes). `auditTrailService.logAudit` is fire-and-forget but still scopes the audit row to `companyId`. Smart categorisation pre-loads rules/patterns per `companyId` to prevent cross-tenant leakage.

## Key tables

- `companies` — master tenant table.
- `audit_logs` — field-level change history, scoped by `company_id`.
- `migration_sessions` — customer migration wizard state.
- `sage_ledger_transactions` / `sage_accounts` — Sage staging tables.
- `payment_transactions` — PayFast transaction log.
- `smart_categorization_rules` / `smart_categorization_patterns` / `categorization_history`.

## Gotchas

- **`sageImportService` BL-40 fix**: both `slt.company_id` AND `sa.company_id` are now filtered in the import query — earlier versions had a cross-tenant SELECT bug fixed in this audit cycle.
- **Payroll PDFs split across two builders** (`payrollPdfBuilders1.ts`, `payrollPdfBuilders2.ts`) purely to stay under the 300-line file limit. They share state via `payrollPdfService.ts`.
- **Smart categorisation pipeline order** is rules → patterns → history → AI fallback. AI fallback is invoked via `aiCategorizationService` only when all three rule-based strategies return `null`.
- **`logAudit` never throws** — it logs any internal error to `log.error` and swallows it. Do not use it for control flow.
- **Sage auto-import** runs via browser session (see `project_sage_sync.md`) — 15 Sage endpoints, correct API names documented there.
