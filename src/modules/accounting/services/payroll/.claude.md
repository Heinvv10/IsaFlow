# Payroll service group

South African payroll engine: PAYE (SARS tax tables), UIF, SDL, ETI, and payroll run lifecycle. The calculation engines are pure TypeScript with no DB dependencies. DB services orchestrate employee, component, and run management against Neon.

## Files

| File | Role |
|---|---|
| `payrollTypes.ts` | Shared types: `PayrollEmployee`, `PayrollComponent`, `PayeInput/Result`, `UifResult`, `EtiInput/Result`, `ValidationResult`, `PayrollLineInput/Result`. |
| `taxTables.ts` | `TAX_2025` + `TAX_2026` configs (brackets, rebates, thresholds, UIF ceiling, ETI parameters). `getTaxYear(month, year)` — SA tax year ends Feb; March of year N → tax year N+1. `getTaxYearConfig(taxYear)` — falls back to latest known year when exact year not registered. |
| `payeEngine.ts` | **Pure.** `calculatePAYE`: annual tax → rebates (primary/secondary/tertiary by age) → medical credits → monthly PAYE. |
| `uifEngine.ts` | **Pure.** `calculateUIF`: 1% employee + 1% employer on leviable income, capped at `uifCeiling` (R17 712/month for 2025). |
| `sdlEngine.ts` | **Pure.** `calculateSDL`: 1% of SDL-leviable income; exempt when company annual payroll < `sdlThresholdAnnual` (R500 000). |
| `etiEngine.ts` | **Pure.** `calculateEti`: Employment Tax Incentive. Eligible: age 18–35, not UIF-excluded, wage ≤ ceiling, ≤ 24 months employed. Year 1 max R1 500/month, Year 2 max R750/month. Linear interpolation for wages above R4 500. |
| `validationEngine.ts` | **Pure.** `validateEmployee`, `validatePayrollLine` — returns `ValidationResult[]` with severity (error/warning/info) and code. |
| `payrollCalculator.ts` | **Pure.** `calculatePayrollLine(input)` — orchestrates all engines for one employee-period. Computes grossPay, taxableIncome, uifLeviable, sdlLeviable, then calls PAYE/UIF/SDL/ETI engines. Returns `PayrollLineResult` including `ComponentBreakdownItem[]`. |
| `payrollRunService.ts` | DB. `listPayrollRuns`, `createPayrollRun` (ON CONFLICT DO NOTHING — duplicate period throws), `getPayrollRun`, `processPayrollRun` (calls calculator for each employee, inserts `payroll_run_lines`), `approvePayrollRun`, `getPayrollRunLines`. |
| `payrollEmployeeService.ts` | DB. Employee CRUD. `listTaxNumbersForCompany` — used for IRP5 export. |
| `payrollEmployeeComponentService.ts` | DB. Per-employee component overrides (earnings/deductions per employee per run). |
| `payrollComponentService.ts` | DB. `getEmployeeComponents` — resolves component amounts for an employee period. |

## Multi-tenant rules

All DB services (`payrollRunService`, `payrollEmployeeService`, `payrollComponentService`, `payrollEmployeeComponentService`) scope queries on `company_id`. Pure engine files have no DB access.

## Key tables

- `payroll_run_headers` — one row per company per period (`period_year`, `period_month`). Unique constraint prevents duplicate runs.
- `payroll_run_lines` — one row per employee per run. Stores all calculated fields.
- `payroll_employees` — employee master per company.
- `payroll_components` — earning/deduction/employer-contribution definitions.
- `employee_components` — links employees to components with amounts.

## Gotchas

- **Tax year boundary**: `getTaxYear(3, 2024)` → 2025 (March 2024 is in the 2025 tax year). Getting this wrong causes incorrect PAYE brackets. Always use `getTaxYear` — do not compute manually.
- **`TAX_2026` is a copy of `TAX_2025`** (`...TAX_2025, year: 2026`) — 2026 tables not yet published by SARS. Update when the budget announces changes.
- **ETI wage floor**: R2 000/month. Employees earning below the floor get R0 ETI even if otherwise eligible. The interpolation formula differs above/below R4 500 — see `etiEngine.ts` inline comments.
- **UIF excluded employees** (`uifExcluded: true`) do not qualify for ETI either — `etiEngine` returns `isEligible: false` with reason `'UIF-excluded employees do not qualify'`.
- **`createPayrollRun` ON CONFLICT DO NOTHING** — if the insert returns no rows, it throws "already exists". Callers should catch this and treat it as a duplicate-run error, not a DB failure.
- **`payrollCalculator.taxableIncome`** floors at 0 (`Math.max(0, ...)`). Pre-tax deductions can reduce taxable income but cannot make it negative.
