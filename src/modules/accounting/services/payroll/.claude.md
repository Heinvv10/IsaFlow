# Payroll service group

South African payroll: PAYE, UIF, SDL, ETI engines + run lifecycle, leave, termination/IRP5 prep, tax directives, UIF declarations. Pure engines have no DB access; DB services are all company-scoped.

## Files

### Pure engines (no DB)
| File | Role |
|---|---|
| `payrollTypes.ts` | Shared types — `PayrollEmployee`, `PayeInput/Result`, `UifResult`, `EtiInput/Result`, `PayrollLineInput/Result`. |
| `taxTables.ts` | `TAX_2025` + `TAX_2026` configs. `getTaxYear(month, year)` — SA tax year ends Feb; March of year N → tax year N+1. `getTaxYearConfig` falls back to latest known year. |
| `payeEngine.ts` | `calculatePAYE`: annual tax → rebates → medical credits → monthly. |
| `uifEngine.ts` | `calculateUIF`: 1% employee + 1% employer, capped at `uifCeiling` (R17 712/m, 2026). |
| `sdlEngine.ts` | `calculateSDL`: 1% of SDL-leviable; exempt when company annual payroll < R500 000. |
| `etiEngine.ts` | `calculateEti`: Employment Tax Incentive. 18–35, non-UIF-excluded, wage ≤ ceiling, ≤ 24 months employed. |
| `validationEngine.ts` | `validateEmployee`, `validatePayrollLine` → `ValidationResult[]`. |
| `irp5ValidationEngine.ts` | Pre-submission field validators for IRP5 certificate export. |
| `payrollCalculator.ts` | `calculatePayrollLine(input)` — orchestrates all engines for one employee-period. |

## Multi-tenant rules

All DB services scope on `company_id`. Pure engines have no DB access.

## Key tables

- `payroll_run_headers` — period unique per company; `journal_entry_id` FK set by approve (mig 399).
- `payroll_run_lines` — per-employee per-run; `run_id` FK (no company_id column).
- `payroll_employees`, `payroll_components`, `payroll_employee_components`.
- `payroll_leave_types` / `_balances` / `_requests` — RLS on `app.current_company_id` GUC (mig 397).
- `tax_directives` (mig 310) + `tax_directive_payments` (mig 403, UNIQUE per directive).
- `uif_declarations` (mig 398) + `journal_entry_id` / `payment_date` (mig 401).

## Gotchas

- **UIF journal employer-half only** — header `total_uif` stores combined employee+employer. DR 5200 Labour only includes the employer half (`total_uif / 2`) because the employee half is deducted from their gross (not an additional company cost). CR 2150 still credits the combined total since both halves go to SARS.
- **Tax year boundary**: `getTaxYear(3, 2024)` → 2025. Always use the helper.
- **`TAX_2026` is a copy of `TAX_2025`** — 2026 tables not yet published by SARS.
- **ETI wage floor**: R2 000/m. Below → R0 ETI. Interpolation formula differs above/below R4 500.
- **UIF-excluded employees** do not qualify for ETI.
- **`createPayrollRun` ON CONFLICT DO NOTHING** — throws "already exists" when insert returns no rows.
- **`payrollCalculator.taxableIncome`** floors at 0.
- **Deduction components (medical/provident/RA) are NOT credited to liability accounts** in the current journal — if an employee has these, the journal will imbalance by their sum. The seed strips them for demo data; a proper fix requires adding deduction-payable credits to `postPayrollRunJournal`.
- **New tables need GRANT statements for `app_user`** — mig 403 / 400 / 402 initially deployed without grants and the APIs 500'd with "permission denied". Always include explicit grants in the migration.
