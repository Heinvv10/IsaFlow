# AFS service group

Annual Financial Statements engine — generates IFRS / IFRS-for-SMEs compliant statement packs (balance sheet, income statement, cash flow, notes) from GL data, renders them to HTML/DOCX/PDF, manages review workflow, and delivers to the client portal. This is the largest single module in the codebase (42 files) and drives the PRD-AFS feature set.

## Functional areas

### Document + version lifecycle
- `afsDocumentService.ts` — AFS document CRUD (a "document" = one year's statements for a company).
- `afsSectionService.ts` — 20+ statement sections (cover, directors' report, balance sheet, etc.) in display order.
- `afsVersionHistoryService.ts` — snapshot each generation so previous drafts are recoverable.
- `afsGenerationJobService.ts` — async job table for long-running renders (queued → running → complete/failed).
- `afsTypes.ts` — shared DTO types; avoid inlining large structural types, import from here.

### Note engine
- `noteEngineService.ts` — top-level: takes AFS document, produces rendered notes.
- `noteDataQueryService.ts` — SQL queries for note data (PPE movement, revenue split, etc.).
- `noteTemplateRegistry.ts` — registry of note templates by standard (IFRS, SMEs).
- `noteGenerators/` — one file per note generator (PPE, intangibles, tax, leases, ...). Add new notes here.
- `noteRendererService.ts` — produces HTML tables + narrative per note.
- `noteAiService.ts` — AI narrative generation for qualitative disclosures.
- `disclosureNoteService.ts` / `disclosureNoteGenerators.ts` (in `reports/`) — companion module.

### Statement calculators
- `cashFlowDirectService.ts` / `cashFlowReconciliationService.ts` — SA GAAP cash flow (direct + reconciliation methods).
- `changesInEquityService.ts` — statement of changes in equity.
- `pisCalculatorService.ts` — Public Interest Score per Companies Act 2008 reg 26; drives audit/review/compiled outcome.
- `kpiScorecardService.ts` — KPI panel (in AFS + in management packs).

### Rendering + export
- `afsHtmlRendererService.ts` + `afsHtmlCoverTemplates.ts` + `afsHtmlTableRenderer.ts` — HTML output path.
- `docxExportService.ts` + `docxTableRenderer.ts` — DOCX via `docx` library.
- `pdfExportService.ts` + `weasyprintService.ts` — PDF via WeasyPrint (Python) service.
- `casewareExportExtService.ts` — Caseware exchange format export.
- `brandProfileService.ts` — per-tenant logo / colour / typography for rendered statements.
- `imageLibraryService.ts` — uploaded signatures / logos / stamp images.

### Review workflow
- `afsReviewService.ts` — state machine: draft → review → approved → issued.
- `afsSectionCommentService.ts` — inline comments per section (reviewer feedback).
- `afsPreExportChecks.ts` — blocker checks before final issue (balance sheet balances, mandatory notes, etc.).
- `afsProofCopyService.ts` — "proof" watermarked copy that can be shared without being final.

### Compliance + CIPC
- `complianceAlertService.ts` — surfaces issues like pending provisional tax, late annual returns.
- `complianceCheckerService.ts` — rule engine that runs the checks above.
- `cipcFilingGuideService.ts` — CoR / annual return filing workflow helper.

### Client portal delivery
- `portalContactsService.ts` — which client contacts see which document.
- `portalNotificationService.ts` — email/SMS on new document available.
- `magicLinkService.ts` — time-boxed signed URLs so portal users can open a document without a full login.
- `packDeliveryService.ts` / `packSchedulerService.ts` — scheduled recurring AFS / management-pack delivery.
- `managementPackConfigService.ts` / `managementPackGeneratorService.ts` — non-statutory monthly management packs (a superset of KPI scorecard).
- `packAiSummaryService.ts` — AI exec summary on the front of a management pack.
- `signumIntegrationService.ts` — Signum e-signature platform adapter for director signatures.

## Multi-tenant rules
Every service scopes by `company_id`. `noteDataQueryService` in particular runs heavy cross-table aggregations — all CTEs and subqueries must include `company_id` in the WHERE. `brandProfileService` and `imageLibraryService` never share assets between companies even if a human super-admin triggers it.

## Key tables
- `afs_documents`, `afs_sections`, `afs_section_comments` — document + section structure.
- `afs_generation_log`, `afs_generation_jobs` — async render tracking.
- `afs_versions` — snapshots for rollback.
- `afs_disclosure_notes`, `afs_note_templates` — note content.
- `afs_brand_profiles`, `afs_image_library` — branding assets.
- `afs_review_workflow`, `afs_approvals` — review state.
- `afs_portal_contacts`, `afs_portal_magic_links`, `afs_portal_notifications` — client access.
- `afs_management_packs`, `afs_pack_schedules`, `afs_pack_deliveries` — management pack.
- `afs_compliance_alerts`, `afs_compliance_rules` — compliance engine.

## Gotchas
- **PIS calculation is mandatory** — `pisCalculatorService.ts` drives whether a company must be audited, reviewed, or compiled. Getting this wrong is a regulatory issue, not a bug. Changes require CA(SA) sign-off.
- **WeasyPrint is a separate Python service** — if `WEASYPRINT_URL` is unreachable, PDF export fails silently unless you grep Sentry. `pdfExportService` retries but doesn't degrade gracefully.
- **Magic links can leak data** — `magicLinkService` emits signed URLs that bypass auth. Token TTL is enforced server-side; never extend it without compliance review.
- **Note generators must register** — adding a file to `noteGenerators/` does nothing unless `noteTemplateRegistry.ts` references it.
- **DOCX tables are column-count sensitive** — `docxTableRenderer` silently drops cells that overflow; verify with an export before relying on a new layout.
- **Compliance alerts fire on read** — `complianceAlertService.list()` triggers rule evaluation as a side effect in some paths. Cache keys live in `cache-keys.ts`.
- **Caseware export is schema-locked** — `casewareExportExtService` targets a specific Caseware version; check with the CA firm before upgrading the library.
- **File: afsProofCopyService.ts watermarks by rewriting the HTML** — proof stamps are rendered inside the HTML tree, not at print time; stripping them requires a re-render.
