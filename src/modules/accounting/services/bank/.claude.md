# Bank service group

Handles all bank-side operations: statement import (CSV/OFX), open-banking feed connections (Basiq/Tink/Plaid), bank reconciliation, transaction allocation to GL/AP/AR, categorisation rules, VLM (Vision Language Model) AI extraction, and multi-document 3-way matching (PO + GRN + Invoice).

## Multi-tenant rules

All DB services scope on `company_id`. `bankAllocationService` explicitly scopes the VAT account lookup to `companyId`. Open banking providers are tenant-specific (each connection row has `company_id`). VLM services are stateless — no tenant data stored, but the extracted result is always persisted under the caller's `companyId`.

## Key tables

- `bank_transactions` — imported/synced rows. `status`: `imported | matched | allocated | reconciled`.
- `bank_reconciliations` — reconciliation sessions per bank account + statement date.
- `bank_feed_connections` — OAuth credentials per tenant per provider.
- `bank_categorisation_rules` — ordered by `priority ASC`; lowest number = highest priority.

## Gotchas

- **VAT account fallback**: `bankAllocationService` resolves VAT accounts via subtype first, then falls back to account codes `1140` (input) / `2120` (output). Companies whose COA pre-dates migration 327 rely on this fallback — do not remove it.
- **Open banking providers (Basiq/Tink/Plaid) are stubbed** — they return sample transaction data until real API keys are set in env. `mock: true` is NOT flagged in these responses; callers cannot distinguish mock from real data.
- **Deduplication**: primary dedup key is `bank_reference` (external TX ID). When absent, the fallback (amount + date + description) can produce false negatives for identical-amount same-day transactions — a known limitation.
- **VLM timeout**: 120 seconds (`VLLM_TIMEOUT` env, default 120 000 ms). AI extraction on large PDFs can hit this in dev.
- **`autoMatch` is not atomic** — it updates each transaction individually. A mid-run crash leaves partial matches; the next reconciliation run picks up remaining unmatched rows.
