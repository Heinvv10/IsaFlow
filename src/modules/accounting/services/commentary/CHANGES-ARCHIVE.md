- 2026-10-07: approve-with-edits.
  - **Rules.** `POST .../[id]/approve` takes an optional `{ text: string }`. The body must be absent/empty or a plain object (a string or array is a 400, never read as "no text"); `text` must be a string, never coerced. An edit writes the trimmed text and leaves `draft_text` the machine draft. CRLF and lone CR become LF before validating and storing. `empty_draft`: no visible character (whitespace, `\p{Cf}`, any `\p{M}` combining mark, Hangul fillers, the braille blank). `invalid_text`: NUL, C0 and C1 controls (except `\n`, `\t`), lone surrogates. `text_too_long`: over `MAX_UNBUDGETED_CHARS = 4000`: an edited row on a pack with no fixed page, and on a fixed page (board) any row, edited or plain, refused before it is costed (#1263); the editor (`CommentaryEditor`) applies the same ceiling on every pack. A PLAIN approval is a compare-and-set on the draft it costed (`AND draft_text = <read>`); a regenerate in between gives `invalid_state` "draft text changed, reload".
  - **Budget.** Board pack only. Page 4 joins every approved row (trimmed, one space, `section_ref, row_ref` order) into one paragraph, and an overflowing page REFUSES the whole pack (`PackRefusal`). `commentaryCost` fills that joined paragraph with page 4's own fill (`packProseFill`) at an UPPER BOUND on its widths (`packProseBound.proseLinesBound`: each code point the faces set at its advance plus the most any kerning pair adds, from the generated `packProseAdvanceData`; a cluster the faces lack from the regular label style's fallback table, read from the gate's own generated copy `packProseFallbackData` by `packFallbackWidthCore`, so the editor loads one style's table and not four; client-safe, no fontkit), refused over `MAX_UNBUDGETED_CHARS` (`text_too_long`) before it is costed, so the cost model never reads unbounded tenant text, and filled by page 4's own fill, Chromium's breaks and each piece whole (so a token wider than the line costs what it prints: two hyphenated 40-letter runs cost 784.7, past the cap; #1263 round 1), at both prose measures (stacked, and two thirds beside the panel) as lines x line-ems, the worse of the two: the gate never reads fewer lines than the page (Hein, 11-10, option ii; `packProseAdvances.test.ts` regenerates and holds the table, REGENERATE_PROSE_ADVANCES=1; `printParity/packProseLinesImage.test.ts` holds it to production). `MAX_APPROVED_PACK_EMS = 760`: the tightest fixture (`liveDemoShortPanelsInput`) holds 787 on caps, digits, wide glyphs, long words and words of 10/26 (prose 813, url 838, CJK 939; other fixtures 1083-1996), ~1450 characters of prose. The whole joined text is costed, not each row, because per-row line ceilings charge every row its half-empty last line (up to ~100 ems over seven rows). Pinned by `packApprovedCommentaryCap.test.ts`: at budget fits 4 fixtures x all kinds (uniform sweep 10..70, alternating cases, 40 seeded mixed texts, rows cut at spaces); 3.5x refuses on all; 1.3x on the tightest. Re-calibrate if page 4's geometry, `PROSE.narrativeBody` or the faces move. A commentary holding a code point the faces do not set is costed at max(that, the pre-#1263 em model's lines) per paragraph (`packProseFloor`, #1264 round 9): the gate stays at or over the page, whose prose is floored the same way; the browser bundle carries `wrapEms` (+0.9 kB, 0.4 kB gzipped).
  - **Which pages.** Board = page 4 "Commentary and actions", fixed sheet, budgeted and serialised per pack by `pg_advisory_xact_lock(hashtextextended('<company>:<kind>:<hash>', 611))` taken BEFORE the pack is read, inside the `withAuth` transaction (the service throws without one); proved on real Postgres by `tests/integration/commentary-budget-race.int.test.ts` (sized from the current budget). Management and monthly never feed approved text to a page model, so they take no budget and no lock; the pack type is recovered by matching `params_hash` against `canonicalParamsHash({type, period_start, period_end})` with the dates read as `to_char(.., 'YYYY-MM-DD')` (proved under non-ISO DateStyle by `tests/integration/commentary-datestyle.int.test.ts`); a row matching no type is budgeted (fail closed). Both integration tests need the disposable fixture DB.
  - **UI.** `CommentaryEditor`: focused textarea prefilled with the draft, `role=status` "about N characters left" from `commentaryCost` with the row substituted at its place, Approve disabled over budget (server is the authority), focus returns to the row on cancel/success, Edit button named by the sentence the row shows (whitespace collapsed, 60 chars). Page 4's prose and derived panel have `overflow-wrap: anywhere` (`styles/packPrintTablesAndProse.css`; `anywhere` not `break-word`, because only it lowers min-content so the `2fr 1fr` grid stops growing; proved in Chromium by `tests/unit/print/packNarrativeLongToken.test.ts`); the share-link `<p>` has `break-words`. `fitBodyPage` (`packs/pages/packNarrativeFit.ts`) words the refusal when approved commentary overflows, naming the sheet from its position.
- 2026-09-26 (R-032 L5): `approveCommentary`, `rejectCommentary` now call `assertNotImpersonating()` (`src/lib/auth/impersonationGuard.ts`) as their FIRST statement: a platform-admin "Login as" session gets `ImpersonationForbiddenError` → 403 `IMPERSONATION_FORBIDDEN` before anything is read or written.
