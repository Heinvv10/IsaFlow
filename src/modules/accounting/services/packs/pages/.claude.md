# services/packs/pages/

## Purpose
Composes the board pack's twelve `PackPage`s from the figure set. `boardPackDocument.ts` fetches; `boardPackPages.ts` (`buildBoardPackPages`) is a synchronous SEQUENCE of per-page composers; `packDocumentAssembly.ts` is its last step (front pages, contents fit, basis page, numbering, `assertPackIntegrity`). `packDocumentWire.ts` is the JSON boundary (`serialisePackPagesDocument` / `adoptPackPagesDocument`).

## Pages and their composers
1 cover, 2 contents: `packFrontMatter` (+ `packContentsFit`, `packUnnumberedPage`). 3 highlights: `packHighlights` + `packHighlightsBlocks`. 4 commentary and actions: `packNarrativePage`, `packNarrativeLayout`. 5 monthly results: `packMonthlyPage` (`packMonthlyResults`, `packMonthlyMeasures`, `packMonthlyCaption`, `packEbitdaMemo`). 6 income: `packIncomeSheet` (+ `packProfitBridge`). 7 position: `packPositionSheet` (+ `packPositionChart`, `packTradeBalances`). 8 cash: `packCashSheet` (+ `packCashBridge`, `packCashTrendChart`). 9 scorecard: `packScorecardSheet`, `packScorecardNotes`, `packScorecard`. 10 trends: `packTrendBlocks`, `packTrendPanelSet`/`packTrendPanelCharts`. 11 matters: `packMattersPage`, `packMattersSelection`, `packMatters`, `packMatterSources`. 12 basis: `packBasisPage`, `packBasis`, `packDefinitions`, `packGlossaryTerms`.

## Block / height / fit model
- A page is a list of typed blocks (`packBlockModel`) plus footnotes. `packPageMetrics.pageMm` sums block heights (`packBlockHeights`, `packTextMetrics` for text wrapping); `pageBoxMm` is the sheet. A statement table or KPI row prints only the figure size the server stamped (`packFigureFitStamp`); the page refuses a block with none, with `fits: false`, with a size outside `FIT_PX`, or a statement table with a label printed to break anywhere and no `labelFloorPx` (`packFigureFitCss.unstampedFigure`, `anywhereFloor`, `markPrintError('pages')`). `packLineBreaks.pieces` breaks between two characters by the pair table scanned in production's image (`packBreakPairs.ts` reads the generated `packBreakPairsData.ts`: classes of the faces' characters, the punctuation, symbols and format characters to U+30FF and a stand-in per script, and every 4-gram of context, pair and context, folded without losing one; Unicode's numeric rule, which reads past one character either side, is `packNumericHold.ts` (`packNumericClassData.ts`, Unicode's classes as production applies them, probed by `printParity/packNumericHoldImage.test.ts`, REGENERATE_NUMERIC=1); re-scan and regenerate with `tests/unit/printParity/packBreakPairsImage.test.ts`, REGENERATE_BREAK_PAIRS=1, velo; `packBreakPairs.test.ts` holds the census in CI, where Playwright's Chromium breaks after a word-opening en or figure dash and production's does not), and at a soft hyphen or zero-width space exactly where Chromium does (`packSoftBreakRanges`, `tests/unit/print/packSoftBreaks.test.ts`), with the hyphen's width (`Piece.hyphen`; a text that ends at one keeps the room on its last line and draws none); a footnote mark after a label's trailing space is a word of its own, and a marked label is split as if a digit followed it, since the mark's digit can hold what stands before it: `markedPieces`, used by every fill and width of a marked label). The ruler shapes with fontkit, which applies the faces' default features as HarfBuzz does but for fractions: HarfBuzz makes one only of U+2044 with a digit on each side, so `packGlyphRuler.shapingInput` hands fontkit a one-sided slash as no code point, and gives every glyph its own code point (fontkit's per-id glyph cache keeps the code points a glyph was first made for).
- **A row label holding a combining mark, a variation selector, a line or paragraph separator, ZWNJ, ZWJ or ZWNBSP, or any character the faces do not set** (`packPrintedText.printsAnywhere`, after `printedText`; the faces' set is `packFallbackWidthData.SELF_HOSTED`, so only row-label text the faces set reaches the pair table; prose (captions, disclosures, footnotes, matters) is set by `packProseLines`, below) is printed to break anywhere (`pack-label-anywhere`) and holds its column open by a floor only: the widest any of its graphemes can be, stamped on the table's fit (`FigureFit.labelFloorPx`), set as the label's `min-width` and counted by the fit gate and the layout. `packAnywhereLabel.ts` measures it as a greedy fill of graphemes: runs the faces set at the ruler's width, any grapheme with a mark or in a fallback face at `FALLBACK.widest` for every code point. A floor the figures leave no room for refuses the pack (`packFigureFloor`); the refusal names the label only where the table fits with it at its own widest piece and the floor alone breaks it (`packFigureFit.refusingLabel`), else it is the figures'. A grapheme of 4+ code points (an emoji ZWJ sequence, a conjunct) refuses at any figure size. No tenant text reaches a statement table's row label today: every one is a fixed statement label, a trend month's label (named by the server, `packTrendService.monthSlots`) or the window over them, held structurally over the demo (with and without a budget, with an unexplained cash movement, over one month), Velocity (a partial month) and a sample of the grid, each of those sources printed at least once (`packRowLabelSources.test.ts`). A source a pack takes only on a branch none of these reach is not held. Page 6's derived caption and its "Lines below zero" disclosure quote row labels; that they are pack wording is held by this test alone, by design (no image test guards the quoted prose: #1261 round 3). KPI tile text refuses marks and fallback glyphs.
- **Print tests match production's glyph advances, not its line breaking** (tenant text is printed as measured: `packPrintedText.ts` drops a U+FE0F after a character with no emoji presentation, at `buildBoardPackPages`' input and in `stampBlock`). #1214's print Chromium (Playwright 145) sets glyphs as production's (Gotenberg 151) does, but breaks some texts differently (a word-opening hyphen, U+2800). Line-break parity with production rests on the velo-only image tests (`printParity/packBreakPairsImage.test.ts`, `packNumericHoldImage.test.ts`); CI reads the print Chromium's breaks as production's (`fixtures/breakPairsCensus.asProduction`) or leaves those texts to the image.
- **The ruler must never under-estimate Chromium.** Prose (every block height, the contents page, page 11's matters) is `packProseLines.proseLines(text, PROSE.<style>, widthMm)`: each word at the faces' own widths (`textExactPx`, at the size and weight of `packProseStyles.PROSE`, held to the CSS by `packProseStyles.test.ts`), filled as the print fills (`packProseFill`): broken where Chromium breaks, by the row labels' splitter (`packLineBreaks.pieces`: hyphens, slashes, between ideographs, set spaces, soft hyphens), each piece kept whole and each line shaped across its joins, collapsible spaces hanging, a soft hyphen's hyphen priced where a line ends at it; only a piece with no break in it that is wider than the line is filled grapheme by grapheme from a new line; `PROSE_GUARD_PX` off each line. Work is linear in the text (tenant text of any length reaches it): clusters come from `packGraphemes` (`Intl.Segmenter`'s, segmented in stretches, since V8's own is superlinear on one long string; every splitter and ruler here uses it), and the width caches beside the fill keep only texts of `KEPT_CHARS` or fewer (`packProseFillLinear.test.ts`). Never continuous fill: a link or hyphenated file name filled as if it broke anywhere read page 11 a sheet short, and a CJK run a line or two (#1263 round 1). Held to production's image on CJK, set spaces, "%" "@" "&", long tokens and at the model's own boundary width (`printParity/packProseLinesImage.test.ts`), on the adversary's links, file names and whole dense packs (`printParity/packProseLinksImage.test.ts`), to CI's Chromium on the faces' text (`print/packTextMetrics.test.ts`, `packSheetCount.test.ts`), and each style to the size and weight the print computes (`print/packProseStylesComputed.test.ts`). KNOWN LIMIT: a joined script in a fallback face (Syriac, Arabic, Mongolian) is priced from the fallback tables letter by letter and can read a line short (80 SADHE); widest pricing would cut the dense pack's Japanese matters 12 to 5 of 15, so the tables stay (Hein, 11-10). Likewise a fallback run its face sets wider than its glyphs alone (katakana "バン" at 2.5% over the tables), and a run Chromium breaks by dictionary (Thai, Lao, Khmer, Myanmar): both are held at the guard, not at the boundary. The em table (`WIDTH_SAFETY`) now sizes only the scorecard's columns, the print furniture and the 11pt calibration (`packTextRulerCalibration.test.ts`).
- **A page that does not fit drops prose and says so; it never starts a thirteenth sheet.** `fitPageToBox` trims optional notes, then footnotes, then the trailing notes of a REQUIRED disclosure (`PackDisclosure.required`), then truncates the longest note. Nothing carrying a figure is trimmed. A required note that cannot fit throws a `PackRefusal`. Omissions are stated in a page footnote.
- Charts step down ONE rung (`packChartRungs`) before prose goes; a chart that already drew its measured height (`...AtHeight`) is preferred over a rung. Page 7's composition chart never goes below `POSITION_CHART_FLOOR_MM`.
- Page 11 spends its own budget first (`mattersBudgetMm`, `packMattersPrinted`); a matter with no rand amount is always kept. Pages 4 and 11 read ONE `SelectedMatters`.

## Rules for composing pages
- A bridge's tick count comes from its plot's height wherever it is drawn with a box — every board-pack bridge, and the management pack's (`legacyWaterfallOption`, a fixed 718 x 320 box): the ask targets `TICK_PITCH_PX` (26px a step — `intervalsFor`; `tickIntervals` does the same for `packPositionChart`), and what is enforced is the 18px legibility floor (`MIN_TICK_PITCH_PX`): `waterfallLayout` lowers the ask until no two drawn ticks are closer, and a plot under 36px draws one step, its two ends, by an explicit `interval`. `waterfallOption` called without a box leaves the count to ECharts.
- A bridge figure is in one of two states, never part on its bar and part off: inside it in `labelInkOn` ink where `figureFitsInside` (`packWaterfallFit.ts` — tall enough AND wide enough, by the face's real advances, `lib/charts/packFigureWidth.ts`), else wholly outside on its own side in ordinary ink. And no figure meets another: `placeFigures` (`packWaterfallPlace.ts`) walks the outside figures left to right and sets one a line further out until it is clear of every figure already placed AND of every bar but its own column's; past two lines the whole chart's figures are set at 10px, then 9px (`FIGURE_SIZES_PX`). `waterfallLayout` and the renderer both call it — the layout to reserve the room, the renderer to use it — so change placement there and nowhere else.
- The rungs at 72 and 110mm, and every box from 72 up, take the FULL chrome with 12px category names — the pack's look, asserted in `packGrownBridge.test.ts`; a box under 72 takes the compact one (`isCompact`). A grown bridge is drawn at `grownHeightMm` (`packChartRungs.ts`): of every whole mm from the chart the page has to its room, the one with the tallest drawn bar (then the larger plot) — a layout per mm, one render — never a compact box that out-draws the 72mm rung. More room only adds candidates, so the picture never shrinks; judging only the tallest box let the axis redraw coarser. Test grown bridges as the pages call them: ONCE, from the rung chart (`packIncomeSheet`, `packCashSheet`). Neither a bridge's axis nor the cash line's prints one figure on two ticks.
- On plots of three gridline steps or fewer, `waterfallLayout` takes the tight domain the figures need (`tightDomain`, one step, ends labelled) where it draws the bridge a quarter taller than the round axis; the layout's reach must equal the room `placeFigures` measures — a pixel more ran axes a whole step too wide.
- Pass `waterfallOption` the box as `{ heightPx, widthPx }` (`svgBoxPx`): the plot is then exact in either face (`waterfallFrame` sizes the left gutter from the ticks and first names; nothing may shrink the plot). A bare height knows no bar's width and reserves a line for every figure. The management pack's bridge is drawn in one fixed box, `LEGACY_WATERFALL_BOX` (718 x 320 — `PackPrintView` is `max-w-[190mm]` on a landscape sheet), and `PackChart` is given that width outright.
- Every outside figure has a paper ground cut to its own box (real advances + 2px), over the bars and under every figure — that is what keeps a gridline out of it; the halo (a stroke-only pass under every fill) only softens its edge and does NOT close the gap at a thousands separator. Never accept a halo as cover in a test. Test with `lostGlyphs`/`illegible`/`textOnText` (`tests/.../support/bridgeSvg.ts`), which read the paint, not the rule.
- Chart text is measured by IBM Plex Sans's own advances (`packFigureWidthPx`, full ASCII from the woff2's `hmtx`; `packTextMeasure` wraps it). The management pack's print view sets its charts in `PACK_FONT_STACK` over the app theme's IBM Plex Mono (`inPrintFace` in `PackSectionView`): the print page loads no Mono, and a fallback face is a second typeface in the PDF.
- Page 8's cash line takes the same pitch budget (`pitchedAxisDomain`), a left gutter sized to its widest tick, and a right gutter sized to its closing figure by `packFigureWidthPx` — never by zrender's `getTextRect`, which charges a non-breaking space a full em. Its axis refuses a step that prints one figure on two ticks (`pitchedAxisDomain`'s `accept`).
- 2026-11-06 (page 3 note over-trimming): the KPI block's height is the lines Chromium sets its tiles in (`packKpiLayout.kpiBlockMm`): column widths are the grid's `1fr` tracks over each column's min-content (`kpiColumnMinPx`), a tile is its label, figure or reason, delta and sparkline (0.797 of the column's width, at most 33mm) with 1mm between, a row is its tallest tile. It replaced `kpiTileHeight` and `kpiColumnWidthsMm` (a quarter-column prose model that read 5.6 to 52.7mm too tall), which kept master fewer notes than pre-#1158 on 184 packs that printed clean. `packKpiLayout.test.ts` holds columns, rows and block to Chromium on 336 packs, portrait and turned landscape; the model's tracks and `measureKpi` are at `PRINT_CONTENT_PX` (658px portrait, 987 landscape) under `launchPrintChromium` (fractional advances): at 657.6px a reason wraps a line the print does not (the model read 5mm tall or 0.07mm short). A tile's label, reason and delta lines are measured one whole line at a time (`lineCount`) and FITTED as Chromium's line breaker fits them: the line's words and a 9pt label's footnote mark summed exactly and floored to the 1/64px unit once, with a margin for Chromium's float noise (half a unit to 512px, growing by a unit per 1,856px past it, widths taken at 12px, so a smaller face's line counts its extra glyphs: `packGlyphRuler.fitUnitsPx(exactPx, fontPx)`, `fitMarginUnits`; `textExactPx`/`reasonExactPx`/`labelMarkExactPx`), and the boxes Chromium rounds up on their own added after (the delta's arrow cue, a soft hyphen's hyphen, a heading's mark), never short on every line `packLineFit.test.ts` and `packRealLines.test.ts` (the pack's own wording, every run) hold to Chromium, in a column the narrowest Chromium can make it (`kpiColumnBoundsPx`: held-open columns at `CHROMIUM_LEAST`, the shared share after the others at `CHROMIUM_MOST`, floored; those bounds count a single run's noise, `RUN_NOISE_UNITS`). Widths a column or the fit gate is sized by stay never short (`runPx`). No wrap guard; the leadings, the 1mm and 8mm gaps and the sparkline cap are Chromium's own to its 1/64px unit (16px, 18.671875, 33.328125; `packKpiLeadings.test.ts`); the sparkline is a unit up at the widest its column can be. Never short, rows and block, no tolerance, and no near tie left: `packKpiLayoutGrid.test.ts` (opt-in, `KPI_GRID=1`) over the grid's 11,520 packs reads no block a line over and no pack dropping a note that fits (was 80 and 40). Statement-table lines are fitted the same way (`packLineWrap.linesForText`, `packTableLayout.headingLineCount`): `packTableLayoutGrid.test.ts` (opt-in, `TABLE_GRID=1`) holds every one of the grid's 6,340 tables to Chromium's line counts exactly. Tile text holding a glyph outside the pack's faces (Thai, Devanagari, Arabic, emoji: a taller fallback line box) is refused with a `PackRefusal`, never under-read. `packKpiLayoutModel.test.ts` pins the whole-line, never-short boundary, the refusal and the sparkline SVG format (an SVG without width and height is refused).
- Every printed money/percentage figure is a `PackFigure` recorded in the provenance map with a unique source; one source printed twice must print the same value.
- Prose claims about another page are derived from what that page drew (`packTrendCrossReference`, `packWindowFootnotes`, `packDisownedBases`, `packPrintsComparative`); never hard-code a pointer or an enumeration. Lists of checks render from `MATTER_SOURCES`.
- Debtor/creditor days and the cycle are on the period's own days (2026-10-07), as the trends page's months are on theirs; page 12's definitions, `PERIOD_COUNTERPARTS['trend-debtor-days'].wholePeriodBasis` and `trendWindowNote` say so and claim no second difference. `packFiguresToFinancialData` must carry `periodDays`.
- A sentence that states a relation takes its result as an input (`narrative/statedRelation.ts`).
- `anchorRow`/`anchorColumn` throw when nothing matches: a footnote with no anchor is a defect.
- Render each chart SVG at `svgBoxFor`'s plot box and pass that same measure to the stylesheet (`--pack-chart-plot-mm`); an SVG whose viewBox mismatches its box is letterboxed (`preserveAspectRatio` meet) and the chart silently shrinks.
- Tables on one page share one column grid (`packScorecardColumns`, `packMattersColumns`).
- Draft status comes only from `packDraftState`; a part month is marked only through `packPartialMonth`, and every first-to-last comparison (page 10 panels and headline, page 3 sparklines) takes the series through `wholeMonthsOf` — the stub is a page-5 row, never an end point; the comparative label comes from `comparativePeriod` via `packPeriodLabel`, never re-formatted.
- A bridge that foots to the cent draws no plug bar; compare floats with `MONEY_TOLERANCE`. A mid-statement subtotal bar is `kind: 'subtotal'`.
