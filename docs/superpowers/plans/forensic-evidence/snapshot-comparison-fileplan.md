## Source facts and reuse limits

Snapshot seals authenticate full canonical material (100MiB canonical ceiling,100000 records,100000 combined evidence+gaps). Indexed header authenticates permissions/counts/snapshot hash; page/chunk descriptors bind ordinal/section/hash. Records are canonical-source/id sorted, but descriptor itself has no identity. Check index items omit findings (separate section); evidence index items include original bytesBase64. Header lacks cutoff/capturedAt/populations/coverage. Public page/chunk service rechecks authority and queries each chunk: invoking it100000times is not an acceptable worker traversal. Comparing descriptor sha256 alone byordinal confuses insertion with edits, includes observation timestamps in checks and rawbyte encoding in evidence, and omits global coverage changes.

Current job pipeline already provides issued saveddelegation, per-person idempotency, current grant intersection,90s leases/3attempts,60s innerdeadline, actual isolated Node65s+2grace,8GiB cgroup/swap0, and atomic publication with succeededgeneration. Reuse it; no callerresourceoverride or inlineHTTP fallback. Current full-material helper remains small-fixture equivalence oracle, not production largejob implementation.
