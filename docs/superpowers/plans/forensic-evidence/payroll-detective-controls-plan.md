## Existing accounting truth and limitations to preserve

- Current source is payroll_run_headers/payroll_run_lines and payroll_employees, not legacy employees/payroll_runs. Existing posting uses buildExactPayrollPlan: gross/employerUIF/SDL/ETI cost, PAYE/UIF/SDL/net/deductions liability legs. Net payroll is already credited to bank in the posting journal; it is not an outstanding net-pay payable invented by this detector.
- payroll_run_headers.journal_entry_id is an owned journal association, not proof of external bank settlement. Reversed/wrong-source/unposted journal links are explicit exceptions/unknown.
- UIF declarations contain explicit journal_entry_id and contributions for a period. Reconcile these actual associations and journal legs when present. PAYE/SDL remittance or individual employee bank confirmation is unknown when no explicit persisted association exists; no period/amount/name fuzzy match is called settlement proof. A paid status alone is not bank confirmation.
- payroll_bank_details stores plaintext secrets. Reuse groups must be formed inside SQL with explicit owned employees and return only employee IDs/group identity. No plaintext account, branch, tax number, employee names or component monetary values in generic finding messages. Current shared account use is a candidate (legitimate shared household account possible), not fraud.
- Employee end_date versus payroll period distinguishes payment after an earlier termination from legitimate final-period wages; this remains a candidate without settlement evidence. Current status alone cannot rewrite historical employment.
- Changed salary components use persisted component breakdown/history and recorded effective dates, not arbitrary updated_at guesses. Missing history remains unknown. Current assignments do not prove historical unchanged salary.
- Zero-cost means complete line gross plus employer costs zero, not merely net_pay zero (which can have legitimate deductions). Active employee absence from a run is a separately labelled population exception/candidate only with in-period employment evidence.
