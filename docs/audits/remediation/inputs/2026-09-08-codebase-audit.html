MFA can be bypassed with the pending-login token

src/lib/auth/gotrue.ts:52

Password login issues a genuine AAL1 access token in sb-pending-mfa. Supplying that token as sb-access-token reaches protected middleware without completing TOTP. Cookie, tenant and platform-admin authentication do not enforce the required MFA assurance. An attacker still needs valid password credentials.

Recommended fix: Enforce the appropriate MFA assurance on protected authentication paths for enrolled accounts. Keep pending-MFA credentials unusable as a completed application session; test cookie, refresh, tenant and admin paths.
