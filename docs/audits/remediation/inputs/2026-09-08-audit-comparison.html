Claims to correct or hold back

  • C2 / F11: Our reproduction gives a more precise failure: new override writes fail legacy NOT NULL requirements; editing the new rate leaves the old rate used by billing.
  • C6 / F12: The authenticated API has an outer withAuth transaction. Keep the demonstrated concurrent double-billing defect; remove the blanket claim that the operation has no transaction.
  • C7 / F09: Normal sequential recalculation excludes schedules already marked paid. Our demonstrated effect is a missing deduction while the loan balance stays reduced, not the stated second decrement.
  • H10: Rejected as reported: the export writes ExcelJS string cells. A generated XLSX stored =HYPERLINK(...) in sharedStrings.xml and contained no formula element. This is a library-behavior reproduction, not an Excel desktop execution test.
  • H36: The blanket NULL fiscal-period allegation misses migration 501, whose BEFORE INSERT trigger resolves a covering period. Cases without a covering period require separate analysis.
  • H50 / F13: A partial unique index allows only one active mandate per company. Activating multiple pending mandates fails; it does not leave multiple active mandates. Our activation-failure finding remains.
  • C21: The report itself marks this unverified and reports development-schema divergence. Do not promote it into a confirmed production defect.
  • H2: ETI formula allegations require checking eligibility, minimum-wage conditions and the effective statutory schedule. Do not accept a formula-only comparison as a confirmed legal calculation defect.
