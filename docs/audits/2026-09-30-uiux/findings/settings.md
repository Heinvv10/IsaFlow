# Settings, admin & developer: audit

Shots: `$AUD/shots/settings/` (flows in `shots/settings/flows/`, flyout destinations in `shots/settings/flyout/`). Scripts: `$AUD/scripts/settings-flows.mjs` (blocks all non-GET `/api` calls, so it cannot save anything), `$AUD/scripts/settings-admin.mjs`. Code: worktree `uiux-audit` @ 66e776d81. Dev DB was read-only (SELECTs only).

## Verdict
Settings is not organised around what an accountant wants to do. The cog flyout has 28 items. It mixes real settings with work screens (Time Tracking, Approvals, eight Group Consolidation reports). It leaves out Billing, VAT, Default Accounts, Accounting Settings, Currencies and Bank Accounts, which sit in the Library > Accounting sub-nav or nowhere.

The worst problem is one that damages data. **Default Accounts shows "Not configured" for every control account, even though all 8 are configured. Pressing its Save Changes button unmarks every system account (AR, AP, VAT in/out, bank, retained earnings, default revenue/expense)** (SET-01).

Company Settings has 14 tabs and one global Save. It has no unsaved-changes guard, the URL does not follow the tab, and the same field is duplicated across tabs. The save path cannot clear a field: blanking a value reports "saved" and keeps the old value. Subscription tenants have no billing page at all.

Developer pages are good: PAT scopes are well explained and the irreversible `write:post` scope is clearly flagged. Error pages for invites and OAuth are clean.

## Top 5 recommendations for this area
1. **Fix Default Accounts now (SET-01).** Read the real system-account state and never mass-clear flags on save. As it stands, one innocent click breaks posting for a company.
2. **Make Company Settings safe to edit:** allow fields to be cleared (SET-03), add an unsaved-changes guard and a sticky save bar (SET-04), check every save response (SET-05), and put the tab in the URL (SET-14).
3. **Rebuild the cog as a settings hub organised by job** (Company · Tax · Accounting · Banking · Users & security · Billing · Integrations), with one layout shell and breadcrumbs. Move work screens out and fold Accounting Settings, Default Accounts, Currencies and the Regional duplicates into it (SET-06/07/08/09/16/17).
4. **Give every tenant a Plan & billing page** (SET-10) and stop the 403 dead ends.
5. **Make settings proactive:** a setup-health checklist with one-click and AI-prefilled fixes (SET-25), and impact previews for ledger-changing settings such as VAT system and control accounts (SET-24).
