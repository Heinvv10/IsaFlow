# Journey (front door + global chrome) — audit

Shots root: `$AUD/shots/journey/` (abbrev. `S/`). Repo refs are in `.worktrees/uiux-audit` (origin/master 66e776d81). Company: ISAFlow Demo unless stated. Tested 2026-09-30 against localhost:3200 (dev DB).

## Verdict
The first 10 minutes don't hold up. The landing surfaces show **numbers that contradict each other and the lists they link to**. There are two landings: `/home`, where login sends a direct client, and `/accounting`, the "Dashboard" tab. `/home` cannot be reached again from the nav, and it disagrees with the dashboard on cash by R37.7M. "Unreconciled bank transactions" is 400, 407, 408, 410 or 120 depending on which surface you read. Global search (Ctrl+K) finds only GL accounts. The customer, supplier, invoice and item queries fail on non-existent columns and the error is swallowed. The chrome itself is modern: tabs, Portfolio/Month-End workbenches, Ctrl+K, a "+" menu and a Close Agent. The Portfolio grid and the Month-End cards are good ideas. But the Library is a 144-link, 3-level Sage-style hover tree. The "+" menu, the tour and the search all partly lie. AI is invisible from the front door.

## Top 5 recommendations for this area
1. **One truth per number.** Build a single metrics service (cash, revenue, overdue AR, due AP, needs-review bank lines, drafts) used by /home, /accounting, Month-End, Portfolio and the list KPI headers. Every tile should deep-link with the exact predicate that produced it (fixes JRN-02/03/04/05/06/29).
2. **Fix Ctrl+K and make it the front door**: repair the broken entity queries (JRN-01), then add page navigation, create actions and a natural-language "ask" (JRN-31/32). This does more to make the product feel modern than anything else here.
3. **One accountant landing.** Portfolio as the cross-client "Today" queue, with clickable cells to client, module and period, merged with /home's "Needs you" and cash questions (JRN-11/12). Fix the stale header on drill-in (JRN-08).
4. **Make the chrome honest**: the "+" menu must open forms (JRN-10), the tour must point at real elements (JRN-19), the 13-badge must reflect real setup state or become a real inbox (JRN-20), and every page needs a document title (JRN-17).
5. **Navigation correctness and access**: fix active-tab rules (JRN-15), click/keyboard/touch flyouts (JRN-16), the mobile header, drawer and table overflow (JRN-18), and the crash when switching company on a record page (JRN-09).
