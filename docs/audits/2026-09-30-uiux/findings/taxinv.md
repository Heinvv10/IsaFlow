# Tax/SARS + Inventory (taxinv) — audit

Shots root: `$AUD/shots/taxinv/` (flows in `flows/`, Brightsphere in `bs/`). Code refs are in `.worktrees/uiux-audit` @ 66e776d81.
Flow script: `$AUD/scripts/taxinv-flows.mjs`. Nothing was saved, submitted, locked or created. I clicked no Save Draft, Mark as Submitted, Lock or Submit button.

## Verdict
The VAT201 prep page (`/accounting/sars/vat201`) is the strongest screen in this area. It has category-aware period chips, a VAT201-vs-GL-control variance table and a pre-filing exceptions panel. That is close to "exceptions-first".
The rest of Tax does not agree with itself:
- Four stores each record whether a return was filed, and each page reads a different one. The Compliance Calendar says "14 overdue, 0 completed" next to "219 submissions".
- The calendar is a static template. It ignores the company's VAT category.
- Two different "VAT201 Return" pages show different figures, with different box numbering, for the same period.
- You cannot drill from any VAT box to its source document.

Inventory is split into two disconnected data models. Items (in the nav) is empty. Products (not in the nav) holds the stock, values it at R0 and shows "—" for quantity on its detail page. Neither model is used by invoices.

## Top 5 recommendations for this area
1. **Use one filed-return record per period** (TAX-01/03/12). Calendar, History, Recon and Locks should all read it, so "overdue", "submitted" and "locked" can never contradict each other.
2. **Build the Tax landing from company settings and include every client** (TAX-02/10/11/19). Use `vatPeriodHelper` for the VAT cycle, add payroll and provisional obligations only when they apply, and show a practice-wide filing inbox on Portfolio.
3. **Have one VAT201 page, numbered as the SARS form, that drills down** (TAX-05/06/07). Clicking a box opens its documents, each linked with a return path. Default to the period that is due (TAX-09) and fix the SAST off-by-one date defaults (TAX-04).
4. **Put exceptions first and show what actually blocks filing** (TAX-08/13). Split blocking from informational counts and add one-click fix links. Replace the recon banner wall with one summary per cause.
5. **Merge Items and Products and connect the result to invoices and bills** (INV-01/02/03/04). Until then every item report is empty and stock is valued at R0.
