## What a SAIPA member gets

### 1. The Close Agent (month-end flagship)
On `/accounting/month-end-workbench`, for any client period:
- Runs a **readiness checklist** (banking reconciled, exceptions cleared, draft
  journals resolved).
- Produces **proposals** — postings to approve, plus advisory flags for what's
  not ready.
- **You decide each one.** Approvals post inside the audit trail; advisories are
  dismiss-only. Accuracy (proposed vs accepted) is shown so you can see how much
  the agent is getting right.

### 2. The bureau cockpit
On `/accounting/portfolio-workbench`: **"N of M clients closable today"** across
your whole portfolio, plus a compliance calendar and bureau rollup — so you work
the exceptions, not every client one by one.

### 3. Full books per client
Invoicing/AR, purchases/AP, inventory, multi-currency, bank reconciliation with
a 4-tier matching engine (OFX/CSV/QIF/PDF/MT940 imports covering all big-5
banks), VAT computation, AFS export, and payroll data — everything a bureau needs
to run a client end to end.

### 4. VAT201 today; SARS e-filing on the way
- **Today:** IsaFlow computes VAT201 with an exceptions panel that reconciles the
  return against the GL to the cent, and flags anything that shouldn't be filed.
- **In progress (not yet live):** direct **VAT201 e-filing via the SARS ISV
  channel**. The software is built and behind a gate; it switches on once IsaFlow
  completes SARS ISV onboarding. Ask us for the current status.
