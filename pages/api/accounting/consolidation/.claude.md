# Consolidation API routes

Group-level consolidation for multi-entity companies. Manages parent-subsidiary relationships, produces a consolidated trial balance across all group entities, and surfaces intercompany elimination balances. Delegates to `services/reports/consolidationService.ts`.

## Endpoints

| Method + path | Handler | Purpose |
|---|---|---|
| `GET /api/accounting/consolidation/companies` | `companies.ts` | List parent + direct subsidiaries for the current company. Response: `{ items }`. |
| `POST /api/accounting/consolidation/companies` | `companies.ts` | Add a subsidiary relationship. Body: `{ childCompanyId, ownershipPercent?, relationshipType? }`. Defaults: `ownershipPercent=100`, `relationshipType='subsidiary'`. |
| `GET /api/accounting/consolidation/trial-balance?periodStart=&periodEnd=` | `trial-balance.ts` | Consolidated trial balance across parent + subsidiaries for the date range. Both params required (YYYY-MM-DD). |
| `GET /api/accounting/consolidation/intercompany-balances?periodStart=&periodEnd=` | `intercompany-balances.ts` | Intercompany elimination balances between group entities. Both params required (YYYY-MM-DD). |

## Auth

- `companies.ts`: `withAuth(withErrorHandler(withCsrf(handler)))` — CSRF on both GET and POST.
- `trial-balance.ts`, `intercompany-balances.ts`: `withAuth(withErrorHandler(handler))` — no CSRF (read-only).

## Response contract

All routes use `apiResponse.success` / `.badRequest` / `.notFound`. Clients MUST unwrap `json.data`.

## Business rules / gotchas

- `childCompanyId` must exist in the `companies` table — verified by a direct SQL lookup before calling the service.
- Callers are not restricted to companies they own; any authenticated user can attempt to add any company as a child. The service layer is expected to enforce business rules around circular relationships.
- `periodStart` and `periodEnd` are both required for the trial balance and intercompany routes; omitting either returns 400.
- The `companies.ts` handler casts `ownershipPercent` with `Number()` — pass a numeric value.
