# consolidation/ (Group consolidation — multi-entity)

Parent-subsidiary relationships, consolidated TB across group entities, intercompany elimination balances. Delegates to `services/reports/consolidationService.ts`.

## Endpoints
- `GET /api/accounting/consolidation/companies` — parent + direct subsidiaries (`{ items }`)
- `POST /api/accounting/consolidation/companies` — add subsidiary `{ childCompanyId, ownershipPercent?, relationshipType? }` (defaults `100`, `subsidiary`)
- `GET /api/accounting/consolidation/trial-balance` — consolidated TB (`?periodStart=YYYY-MM-DD&periodEnd=YYYY-MM-DD` both required)
- `GET /api/accounting/consolidation/intercompany-balances` — elimination balances (`?periodStart=&periodEnd=` both required)

## Auth
- `companies`: `withAuth(withErrorHandler(withCsrf(handler)))` — CSRF on GET and POST
- `trial-balance`, `intercompany-balances`: `withAuth(withErrorHandler(handler))` — read-only

## Business rules
- `childCompanyId` verified to exist in `companies` table via direct SQL before service call
- No ownership gate — any authed user of the parent can attempt to register any company as child; service layer enforces circular-relationship rules
- `ownershipPercent` coerced via `Number()` — numeric input required
- Omitting `periodStart` or `periodEnd` returns 400 on TB / intercompany routes
