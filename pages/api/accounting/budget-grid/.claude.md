# Budget grid API (`pages/api/accounting/budget-grid/`)

The budget workspace's routes (budgets P2). Version lifecycle (create, status, copy, primary, delete) stays in P1's `budget-versions/**`; nothing here creates a version except the seed wizard, through P1's `createVersion`.

## Endpoints

| Method + path | Handler | Purpose |
|---|---|---|
| `GET /api/accounting/budget-grid?version_id=` or `?fiscal_year=` | `index.ts` | Read model (primary, else newest version of the year; `version: null` when the year has none). `&cells_only=1` → cells + token only. |
| `GET /api/accounting/budget-grid/prior-actuals?fiscal_year=&grain=` | `prior-actuals.ts` | PY actuals at `company`/`cc1`/`cc2`/`bu`. |
| `POST /api/accounting/budget-grid/save` | `save.ts` | `{ versionId, expectedUpdatedAt, cells[] }` batch save (`amount: null` deletes). 32 MB body: MAX_SAVE_CELLS 200 000 × ~150 B of JSON. |
| `POST /api/accounting/budget-grid/seed` | `seed.ts` | Wizard: new draft version from PY actuals +x%, a version copy, or blank. |
| `GET /api/accounting/budget-grid/template?version_id=&grain=` | `template.ts` | `.xlsx` template (viewers allowed). |
| `POST /api/accounting/budget-grid/import-preview` | `import-preview.ts` | multipart `file` + `versionId` → diff preview. Writes nothing; commit goes through `save`. |

## Auth
GETs: `withAuth(withErrorHandler(...))`. Writes (save, seed, import-preview): `withAuth(withErrorHandler(withCsrf(withWriteAccess(...))))`. `makePrimary` on seed needs owner/admin (checked in the service). `withRole` is never widened.

## Response contract
Errors go through `respondBudgetVersionError`: 400 input/grain (the message names the account), 403 role, 404 version not found (another tenant's included), 409 `BUDGET_VERSION_LOCKED` / `BUDGET_VERSION_STALE` (`{currentUpdatedAt, status}`), 503 on a held row lock. Types are registered in `src/lib/apiRoutes.ts`.

## Gotchas
- The token is P1's UTC ISO text with microseconds; send back exactly what the read returned.
- An import preview's token goes stale if anyone saves in between: commit then 409s and the user re-runs the preview.
