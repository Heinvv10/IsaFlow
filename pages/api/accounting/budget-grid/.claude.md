# Budget grid API (`pages/api/accounting/budget-grid/`)

The budget workspace's routes (budgets P2). Version lifecycle (create, status, copy, primary, delete) stays in P1's `budget-versions/**`; nothing here creates a version except the seed wizard, through P1's `createVersion`.

## Endpoints

| Method + path | Handler | Purpose |
|---|---|---|
| `GET /api/accounting/budget-grid?version_id=` or `?fiscal_year=` | `index.ts` | Read model (primary, else newest version of the year; `version: null` when the year has none). `&cells_only=1` → cells + token only. |
| `GET /api/accounting/budget-grid/prior-actuals?fiscal_year=&grain=` | `prior-actuals.ts` | PY actuals at `company`/`cc1`/`cc2`/`bu`. |
| `POST /api/accounting/budget-grid/save` | `save.ts` | `{ versionId, expectedUpdatedAt, cells[] }` batch save; delete a cell with `amount: null, clear: true` (a null without `clear: true`, `clear: true` with an amount, or the nil UUID as any id is 400 naming the cell). The body is read by `withBodyFirst` (src/lib/readJsonBody.ts) OUTSIDE withAuth, before any connection or transaction, only for a caller who passes CSRF and holds a signed session; it is parsed after withAuth's checks. Limits: 18 MB (413), 290 s in all (17.2 MB at 512 kbit/s), 10 s between chunks (400 REQUEST_BODY_TIMEOUT). At most MAX_SAVE_CELLS (100 000) cells. |
| `POST /api/accounting/budget-grid/seed` | `seed.ts` | Wizard: new draft version from PY actuals +x%, a version copy, or blank. |
| `GET /api/accounting/budget-grid/template?version_id=&grain=` | `template.ts` | `.xlsx` template (viewers allowed). |
| `POST /api/accounting/budget-grid/import-preview` | `import-preview.ts` | multipart `file` + `versionId` → diff preview. Writes nothing; commit goes through `save`. |

## Auth
GETs: `withAuth(withErrorHandler(...))`. Writes (save, seed, import-preview): `withAuth(withErrorHandler(withCsrf(withWriteAccess(...))))`. `makePrimary` on seed needs owner/admin (checked in the service). `withRole` is never widened.

## Response contract
Errors go through `respondBudgetVersionError`: 400 input/grain (the message names the account), 403 role, 404 version not found (another tenant's included), 409 `BUDGET_VERSION_LOCKED` / `BUDGET_VERSION_STALE` (`{currentUpdatedAt, status}`), 503 on a held row lock. Types are registered in `src/lib/apiRoutes.ts`.

## Gotchas
- The token is P1's UTC ISO text with microseconds; send back exactly what the read returned.
- An import preview's token goes stale if anyone saves in between: commit then 409s and the user re-runs the preview.
- `import-preview` order: `withBodyFirst` (per-user bucket charged before any byte) (raw upload read OUTSIDE withAuth: 10 MB + 64 KB, 200 s total, 10 s idle; only for a CSRF-checked caller with a signed session) → withAuth → … → formidable on the buffered bytes. No pooled connection is held while a client uploads.
- Rate limits are per USER (`budget-import:<userId>`, `budget-template:<userId>`, 60 / 15 min), never per company+user.
- Early body reads (`withBodyFirst` in src/lib/readJsonBody.ts, reader in readRawBody.ts) gate on the SAME `verifyToken` withAuth calls plus CSRF, then charge a per-user rate bucket before any byte (`budget-save:<userId>` 120/min, `budget-import:<userId>` 60/15 min; literal keys in the routes for the census; a bucket outage is a logged 503). Budgets count bytes RECEIVED and are held until the handler finishes: per user one route maxBytes and 2 reads (429), per process 64 MB (503), in three tiers (src/lib/readRawBody.ts): tiny ≤ 64 KB counts against no process lane (15 s total; a normal grid save can never be starved), small ≤ 1 MB a 32 MB lane (30 s), large a 64 MB lane (route total) with a 16 KB/s floor averaged from the first byte after a 10 s grace (512 kbit ADSL passes 4×). A body moves up a tier with all its bytes; an undeclared body may overflow into the large lane. A body not read early is refused (400 REQUEST_BODY_NOT_READ), never read inside the transaction. aal1 users cost two GoTrue `/user` calls per request (the gate's and withAuth's).
- A save batch that changes nothing returns 200 with the current token and writes no audit row (no false STALE for others).
