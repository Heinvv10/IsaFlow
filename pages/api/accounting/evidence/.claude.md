# evidence/

## Endpoints / Modules
PRD-05 Phase 2 evidence-first drill endpoints. Both delegate to `evidenceGraphService`.

- `GET /api/accounting/evidence/trial-balance/[accountId]` — accepts an account UUID or company-scoped account code; query params `?from=YYYY-MM-DD&to=YYYY-MM-DD&limit=N&cost_centre_id=UUID`. Returns `{ rows, count }`; rows use the camelCase `AccountEvidenceRow` contract from `evidenceGraphService.ts`. Powers the "Evidence" modal on TB / IS / BS.
- `GET /api/accounting/evidence/je/[jeId]` — drill from a specific JE to its source document. Returns `{je, lines, document: CapturedDocumentRow | null}`. 404 when JE is cross-company or missing.

## Auth
`withAuth(withErrorHandler(handler))` — read-only, no withWriteAccess.

## Request / Response
Query params on trial-balance: `from`, `to` ISO dates optional; `limit` default 100; optional `cost_centre_id` must be one UUID. Response is `{ success: true, data: { rows, count } }`.

## Business rules
- The selected centre matches independent legacy `cost_center_id` OR explicit `cc1_id` OR `cc2_id`; every match remains company-scoped.
- JE rows with `source_document_id=null` are returned but render a muted dash in the UI — common for legacy JEs (migration 409 backfilled `posting_agent='legacy:human'` but left source IDs null).
- `document_thumbnail_url` is always null currently; the UI falls back to vendor/reference display.
