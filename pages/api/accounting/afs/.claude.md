# AFS API routes

Annual Financial Statements engine. Manages AFS documents (full IFRS / IFRS for SMEs) and management packs through their full lifecycle: draft → review → partner_review → signed_off → filed. Includes section management, PDF/DOCX/Caseware export, PIS scoring, IFRS compliance checks, Signum e-signing, and a client-facing portal surface.

## Endpoints

Top-level:

| Method + path | Handler | Purpose |
|---|---|---|
| `GET /api/accounting/afs` | `index.ts` | List AFS documents for the company. |
| `POST /api/accounting/afs` | `index.ts` | Create document. Body: `{ fiscalYear?, period?, documentType, reportingFramework }`. `fiscalYear` required for `afs`; `period` (YYYY-MM) for `management_pack`. |
| `POST /api/accounting/afs/generate-pack` | `generate-pack.ts` | Trigger manual management-pack generation for a period. Body: `{ period: 'YYYY-MM' }`. Throws `DuplicatePackError` if pack already exists. |
| `GET /api/accounting/afs/management-pack-config` | `management-pack-config.ts` | Read the company's management-pack generation config. |
| `GET\|POST /api/accounting/afs/portal-contacts` | `portal-contacts.ts` | List / create portal contacts (directors, CFOs, etc.) who can sign or view AFS. |
| `GET\|PATCH\|DELETE /api/accounting/afs/portal-contacts/[contactId]` | `portal-contacts/[contactId].ts` | Single contact operations. |
| `GET\|POST /api/accounting/afs/images` | `images.ts` | List / upload brand images (logo, etc.) for AFS rendering. |
| `GET\|PUT\|DELETE /api/accounting/afs/images/[imageId]` | `images/[imageId].ts` | Single image operations. |
| `GET\|PUT /api/accounting/afs/brand-profile` | `brand-profile.ts` | Read / update the brand profile (colours, logo, font) used in PDF export. |

Per-document (`[documentId]`):

| Method + path | Handler | Purpose |
|---|---|---|
| `GET /api/accounting/afs/[documentId]` | `[documentId]/index.ts` | Fetch document + all sections. |
| `POST /api/accounting/afs/[documentId]/generate` | `[documentId]/generate.ts` | Enqueue a generation job. Blocked if status is `signed_off` or `filed`. Returns `{ job }`. |
| `GET /api/accounting/afs/[documentId]/export?format=` | `[documentId]/export.ts` | Export as `pdf`, `docx`, or `caseware`. Streams binary for pdf/docx; returns file manifest for caseware. |
| `POST /api/accounting/afs/[documentId]/submit-for-review` | `[documentId]/submit-for-review.ts` | Transition document to `in_review`. Throws `ReviewError` on invalid state. |
| `POST /api/accounting/afs/[documentId]/sign-off` | `[documentId]/sign-off.ts` | Partner sign-off. Returns `ErrorCode.CONFLICT` if state machine disallows it. |
| `POST /api/accounting/afs/[documentId]/send-for-signing` | `[documentId]/send-for-signing.ts` | Send to Signum e-signing. Requires status `partner_review`. Body: `{ signerContactIds: string[] }`. Contacts must have role `director` or `cfo`. |
| `POST /api/accounting/afs/[documentId]/compliance-check` | `[documentId]/compliance-check.ts` | Run IFRS compliance checks. Delegates to `complianceCheckerService.ts`. |
| `GET /api/accounting/afs/[documentId]/pis-score` | `[documentId]/pis-score.ts` | Compute Public Interest Score from live GL data. |
| `GET\|POST /api/accounting/afs/[documentId]/sections/[sectionId]` | `[documentId]/sections/[sectionId]` | Read / update individual AFS section content and overrides. |
| `POST /api/accounting/afs/[documentId]/sections/reorder` | `[documentId]/sections/reorder.ts` | Reorder sections. |
| `GET\|POST /api/accounting/afs/[documentId]/statements/...` | `[documentId]/statements/` | Cash flow (direct/reconciliation), changes in equity, deliver. See subdirs. |
| `GET\|POST /api/accounting/afs/management-packs/[packId]/...` | `management-packs/[packId]/` | Management pack sub-resources. See subdirs. |

Cron:

| Method + path | Handler | Purpose |
|---|---|---|
| (internal) | `cron/management-packs.ts` | Scheduled job that auto-generates management packs. |

## Auth

All staff-facing routes: `withAuth(withErrorHandler(handler as never))` — no explicit CSRF on most AFS routes. `send-for-signing` and state-transition POSTs also use `withAuth` only. Portal routes use `withPortalAuth` (see `portal/` group).

## Response contract

`apiResponse.success` / `.created` / `.notFound` / `.badRequest`. `ReviewError` is caught and mapped to `ErrorCode.CONFLICT` (HTTP 409). Export routes stream binary directly — do not unwrap `json.data`.

## Business rules / gotchas

- `documentType` values: `afs | management_pack`. `reportingFramework` values: `ifrs_smes | full_ifrs`.
- Generation is async — `POST .../generate` enqueues via `afsGenerationJobService.ts`; poll job status separately.
- `send-for-signing` reads rendered HTML from disk via `afsStorage.afsHtmlPath()`; returns 400 if HTML not yet generated.
- Only contacts with role `director` or `cfo` may be listed as signers.
- `export?format=caseware` returns a file manifest (names + sizes), not raw binaries.
- Services live in `src/modules/accounting/services/afs/`.
