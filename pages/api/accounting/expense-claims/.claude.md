# expense-claims/ (PRD-05 Phase 10 — employee expense claims + mileage)

## Endpoints
- `GET /api/accounting/expense-claims` — list (`?employeeId=&status=`)
- `POST /api/accounting/expense-claims` — create draft `{ employeeId, claimDate, title, description?, lines? }`
- `GET|POST|DELETE /api/accounting/expense-claims/[id]` — get / add line / hard-delete (cascades)
- `POST /api/accounting/expense-claims/[id]/submit` — draft → submitted
- `POST /api/accounting/expense-claims/[id]/approve` — body `{ decision: 'approve'|'reject', reason? }`
- `POST /api/accounting/expense-claims/[id]/post` — post to GL, body `{ reimbursementAccountId, vatInputAccountId? }`
- `PATCH|DELETE /api/accounting/expense-claims/[id]/lines/[lineId]` — update/remove line (draft only)
- `POST /api/accounting/expense-claims/mileage-trip` — compute SARS km rate; without `claim_id` returns preview, with it adds line

## Auth
`withAuth(withErrorHandler(withWriteAccess(...)))` on all mutating routes; GET uses `withAuth(withErrorHandler(...))`.

## Business rules
- UUID-guarded on every `[id]` and `[lineId]` (regex before DB)
- State machine: `draft → submitted → approved → posted`; lines mutable in `draft` only
- `post` requires `reimbursementAccountId` (usually employee payable or petty cash)
- Mileage-trip auto-picks default expense account (name ILIKE '%travel%'|'%motor%'|'%mileage%', else first active expense)
- `getCompanyKmRate` reads company SARS prescribed rate; PWA uses preview mode (no `claim_id`) before confirming
- Approve/reject require `req.user.id` (logged in approver)
