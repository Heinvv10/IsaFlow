# Practice API routes

Accounting practice management module — tracks clients, staff, time entries, WIP (work-in-progress), billing, and job workflow for professional services firms. All routes are tenant-scoped to the practice company. Services live in `src/modules/accounting/services/practice/`.

## Endpoints

| Method + path | Handler | Purpose |
|---|---|---|
| `GET\|POST /api/accounting/practice/clients` | `clients.ts` | List practice clients (with filters: status, search, groupId, pagination) / create a client. POST seeds default job categories. |
| `GET\|PUT\|DELETE /api/accounting/practice/clients/[id]` | `clients/[id]` | Single-client CRUD. See subdir. |
| `GET\|POST /api/accounting/practice/client-contacts?clientId=` | `client-contacts.ts` | List / create contacts for a practice client. |
| `GET\|PUT\|DELETE /api/accounting/practice/client-contacts/[id]` | `client-contacts/[id]` | Single-contact CRUD. See subdir. |
| `GET\|POST /api/accounting/practice/client-groups` | `client-groups.ts` | List / create client groups (e.g. family, group-of-companies). |
| `GET\|POST /api/accounting/practice/job-categories` | `job-categories.ts` | List / create job categories. |
| `GET\|PUT\|DELETE /api/accounting/practice/job-categories/[id]` | `job-categories/[id]` | Single job category CRUD. See subdir. |
| `GET\|POST /api/accounting/practice/work-items` | `work-items.ts` | List / create work items (tasks within a job). |
| `GET\|PUT\|DELETE /api/accounting/practice/work-items/[id]` | `work-items/[id]` | Single work item CRUD. See subdir. |
| `GET\|POST /api/accounting/practice/time-entries` | `time-entries.ts` | List time entries (with filters) / create. |
| `GET\|PUT\|DELETE /api/accounting/practice/time-entries/[id]` | `time-entries/[id]` | Single time-entry CRUD. See subdir. |
| `GET\|POST /api/accounting/practice/staff-rates` | `staff-rates.ts` | List staff rates for a user / create a rate. `?userId=` required on GET. |
| `GET\|PUT\|DELETE /api/accounting/practice/staff-rates/[id]` | `staff-rates/[id]` | Single staff rate CRUD. See subdir. |
| `GET\|POST /api/accounting/practice/staff-cost-rates` | `staff-cost-rates.ts` | Staff COST rate cards (used for margin reporting, mig 386). |
| `GET\|PUT\|DELETE /api/accounting/practice/staff-cost-rates/[id]` | `staff-cost-rates/[id]` | Single cost-rate CRUD. |
| `GET /api/accounting/practice/rate-resolve?userId=&clientId=&date=` | `rate-resolve.ts` | Resolve effective billing rate. Read-only. |
| `GET /api/accounting/practice/wip` | `wip.ts` | WIP board by client. Read-only. |
| `POST /api/accounting/practice/wip/invoice` | `wip/invoice.ts` | Generate customer_invoice from approved unbilled time entries. Body: `{ practiceClientId, timeEntryIds, taxRate? }`. Requires practice client `link_customer_id`. |
| `GET\|POST /api/accounting/practice/jobs` | `jobs.ts` | List / create practice jobs. |
| `GET\|PUT\|DELETE /api/accounting/practice/jobs/[id]` | `jobs/[id]` | Single job CRUD. |
| `GET\|POST /api/accounting/practice/tasks` | `tasks.ts` | List / create practice tasks. |
| `GET\|PUT\|DELETE /api/accounting/practice/tasks/[id]` | `tasks/[id]` | Single task CRUD. |
| `GET\|POST /api/accounting/practice/entry-templates` | `entry-templates.ts` | List / create time-entry templates. |
| `GET\|POST /api/accounting/practice/report-recipients` | `report-recipients.ts` | Scheduled report recipient CRUD. |
| `GET /api/accounting/practice/reports/*` | `reports/` | Management reports (utilisation, profitability, WIP aging, revenue pipeline, compliance, service mix). |
| `POST /api/accounting/practice/clients/bulk` | `clients/bulk.ts` | Bulk client operations (import, status change). |
| `GET\|POST /api/accounting/practice/clients/[id]/rate-overrides` | `clients/[id]/rate-overrides.ts` | Per-client-per-staff billing override CRUD (mig 395). |

## Auth

- Write routes (POST/PUT/DELETE): `withAuth(withErrorHandler(withCsrf(withWriteAccess(handler))))`.
- Read-only routes (`rate-resolve.ts`, `wip.ts`, some GETs on mixed handlers): `withAuth(withErrorHandler(handler))` — no CSRF.

## Response contract

`apiResponse.success` / `.created` / `.badRequest` / `.notFound` / `.methodNotAllowed`. Clients MUST unwrap `json.data`.

## Business rules / gotchas

- Creating a client (`POST /clients`) triggers `seedDefaultCategories` in the background — failure is non-fatal (logged as warn, does not roll back client creation).
- `rate-resolve` resolves precedence: client-specific staff rate → default staff rate → category default.
- `wip.ts` uses `withAuth(withErrorHandler(handler))` without `withWriteAccess` — this is intentional; WIP is read-only and should be accessible to `viewer` role.
- `billingModel` and `status` are required when creating a client.
