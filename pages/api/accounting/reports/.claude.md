# Reports (inventory/sales/purchases) API routes

Inventory and sales/purchase analysis reports housed in the `reports/` directory. These complement the flat `reports-*.ts` files in the parent directory which cover financial statements. This directory focuses on stock-movement, item valuation, sales analysis, and customer communication reports.

## Endpoints

| Method + path | Handler | Purpose |
|---|---|---|
| `GET /api/accounting/reports/cash-movement` | `cash-movement.ts` | Bank transactions grouped by account showing inflows and outflows for a period. |
| `GET /api/accounting/reports/customer-communication` | `customer-communication.ts` | Customer communication log. Filters: `customer_id`, `from`, `to`, `status`, `page`, `limit`. Supports `?format=csv` for download. |
| `GET /api/accounting/reports/item-listing` | `item-listing.ts` | Master list of all stock items with category, pricing, and stock details. |
| `GET /api/accounting/reports/item-movement` | `item-movement.ts` | Stock movement log (in / out / adjustments) per item with running balance. |
| `GET /api/accounting/reports/item-quantities` | `item-quantities.ts` | Current on-hand quantities per item with min-stock alerts. |
| `GET /api/accounting/reports/item-valuation` | `item-valuation.ts` | Current stock value (qty × cost) by item, totals by category. |
| `GET /api/accounting/reports/purchases-by-item` | `purchases-by-item.ts` | Purchase analysis grouped by item for a date range. |
| `GET /api/accounting/reports/purchases-by-supplier` | `purchases-by-supplier.ts` | Purchase summary grouped by supplier for a date range. |
| `GET /api/accounting/reports/sales-by-customer` | `sales-by-customer.ts` | Sales summary grouped by customer for a date range. |
| `GET /api/accounting/reports/sales-by-item` | `sales-by-item.ts` | Sales analysis grouped by item for a date range. |

## Auth

- `cash-movement.ts`, `customer-communication.ts`: `withAuth(withErrorHandler(handler))` — no `withWriteAccess`.
- All item/stock/sales/purchases reports: `withAuth(withErrorHandler(withWriteAccess(handler)))` — write-access middleware applied (GETs pass through untouched, ensuring `owner | admin | manager` role).

## Response contract

All routes return `apiResponse.success`. `customer-communication.ts` additionally supports `?format=csv` which streams a CSV file directly (bypasses `apiResponse`). Clients MUST unwrap `json.data` for JSON responses.

## Business rules / gotchas

- The `reports/` directory is separate from the 25+ flat `reports-*.ts` files in the parent `pages/api/accounting/` directory — those cover GL reports (trial balance, balance sheet, income statement, VAT return, etc.).
- Item stock reports read from `items`, `stock_adjustments`, and related tables; they are not GL-based.
- All reports are GET-only — no mutations in this directory.
- Date range params are typically `from` / `to` (YYYY-MM-DD) but verify per endpoint as naming is not fully standardised.
