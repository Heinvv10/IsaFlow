# supplier-statements/

## Endpoints / Modules
PRD-05 Phase 7 supplier statement reconciliation. Upload a supplier's monthly statement PDF; VLM extracts lines; per-line match against `supplier_invoices` reports variance.

- `GET  /api/accounting/supplier-statements` — optional `?supplierId=...`. **Single JOIN query** (N+1 fixed in commit d471d8c) — returns headers only; `lines` and `missingInvoices` come as empty arrays in list view.
- `POST /api/accounting/supplier-statements` — multipart with `supplierId`. Store PDF, extract via `vlmSupplierStatementService`, persist reconciliation + lines.
- `GET  /api/accounting/supplier-statements/[id]` — full recon with matched lines + missingInvoices.
- `POST /api/accounting/supplier-statements/[id]/rematch` — re-runs match logic without re-calling VLM (use when new invoices landed after the initial upload).
- `POST /api/accounting/supplier-statements/[id]/mark-reconciled` — status='reconciled'.

## Auth
`withAuth(withErrorHandler(withWriteAccess(handler)))` for mutating.

## Request / Response
SupplierStatementReconciliation: `{id, supplierId, supplierName, statementDate, period, supplierBalance, isaflowBalance, variance, status, missingInIsaflowCount, missingInStatementCount, amountDiffCount, lines[], missingInvoices[], createdAt, reconciledAt}`.

Lines carry `{matchedSupplierInvoiceId, matchedInvoiceNumber, matchConfidence, mismatchReason ∈ missing_in_isaflow/missing_in_statement/amount_diff/date_diff}`.

## Business rules
- **Match ladder (per line)**: exact reference match → confidence 1.0 + mismatch_reason null (unless amount >R0.01 off → 'amount_diff', or date >7d off → 'date_diff'). Else fuzzy amount ±0.5% + date ±3d → 0.85. Else `missing_in_isaflow`.
- **Missing-in-statement pass**: after per-line matching, every `supplier_invoices` in the period without a matched line becomes a `missing_in_statement` record (persisted as synthetic lines with the invoice metadata).
- **Variance = supplier_balance − isaflow_balance** computed once at creation; `mark-reconciled` gates on `|variance| ≤ R0.01 AND all lines resolved`.
- **List view returns empty `lines`** — performance optimisation (d471d8c). Callers that need per-line data fetch `GET /[id]`.
