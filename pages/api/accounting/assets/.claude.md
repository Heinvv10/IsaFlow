# assets/ (Fixed Asset Register — PRD-04)

Sub-routes for the dual-track FAR (policy/IFRS vs tax/SARS). Register CRUD itself lives at `pages/api/accounting/assets.ts` (flat file). This subtree holds per-asset workflows and cross-portfolio reports.

## Endpoints
- `GET /api/accounting/assets/far-report` — full FAR `?asAt=YYYY-MM-DD` (default today); reads `asset_period_ledger`
- `GET /api/accounting/assets/far-report-xlsx` — streams same as ExcelJS `.xlsx`
- `GET /api/accounting/assets/afs-summary` — IAS 16 PPE movement note grouped by `ias16_group` (`?period=YYYYMM`)
- `GET /api/accounting/assets/deferred-tax` — schedule by category (`?period=YYYYMM`)
- `GET /api/accounting/assets/below-threshold` — assets where `purchase_price < category.capitalization_threshold`
- `POST /api/accounting/assets/below-threshold` — expense to GL, body `{ assetId }`
- `POST /api/accounting/assets/[assetId]/dispose` — body `{ proceeds?, disposalDate, disposalType?, notes? }`
- `GET /api/accounting/assets/[assetId]/period-ledger` — all ledger rows for one asset, ordered by period

## Auth
- Read routes (`far-report`, `far-report-xlsx`, `afs-summary`, `deferred-tax`, `period-ledger`): `withAuth(withErrorHandler(handler))`
- Mutating routes (`below-threshold` POST, `dispose`): `withAuth(withCsrf(withErrorHandler(handler)))`

## Request / Response
- `period` is `YYYYMM` (6 digits), NOT `YYYY-MM`
- `asAt` defaults to today when omitted
- XLSX route writes binary directly (`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`) — do NOT unwrap `json.data`
- Others use `apiResponse.success|.badRequest|.notFound`

## Business rules
- FAR uses `DISTINCT ON (asset_id) ORDER BY asset_id, yyyymm DESC` for latest snapshot per asset
- Disposal upserts `asset_period_ledger` via `ON CONFLICT ... DO UPDATE` (idempotent)
- `dispose` blocks if asset already `status='disposed'`
- `below-threshold` POST delegates to `glCrossModuleHooks.postCapitalizationExpenseToGL`
- Dispose calculates both policy and tax gain/loss, posts GL via `glCrossModuleHooks.postAssetDisposalToGL`
