# Assets API routes

Fixed Asset Register (FAR) sub-routes sitting beneath the primary `assets.ts` flat handler. Covers dual-track depreciation (policy/IFRS vs tax/SARS), disposals with gain/loss computation, deferred tax schedules, below-threshold capitalization decisions, and Excel/JSON FAR exports. The `assets/` directory holds per-asset and cross-portfolio endpoints; CRUD for the register itself is in the flat file `pages/api/accounting/assets.ts`.

## Endpoints

| Method + path | Handler | Purpose |
|---|---|---|
| `GET /api/accounting/assets/far-report?asAt=YYYY-MM-DD` | `far-report.ts` | Full FAR as at any date. Reads `asset_period_ledger` (latest period ≤ asAt per asset). Returns `{ assets[], totals }`. Delegates to inline SQL — no service layer. |
| `GET /api/accounting/assets/far-report-xlsx?asAt=YYYY-MM-DD` | `far-report-xlsx.ts` | Streams the same FAR data as an ExcelJS `.xlsx` download. Bypasses `apiResponse` — writes binary directly. |
| `GET /api/accounting/assets/below-threshold` | `below-threshold.ts` | List assets whose `purchase_price < category.capitalization_threshold` (default 5000). |
| `POST /api/accounting/assets/below-threshold` | `below-threshold.ts` | Expense a specific below-threshold asset to GL. Body: `{ assetId }`. Delegates to `glCrossModuleHooks.postCapitalizationExpenseToGL`. |
| `GET /api/accounting/assets/deferred-tax?period=YYYYMM` | `deferred-tax.ts` | Deferred tax schedule aggregated by asset category for a given period. Delegates to `farAfsService.aggregateDeferredTax`. |
| `POST /api/accounting/assets/[assetId]/dispose` | `[assetId]/dispose.ts` | Dispose asset. Body: `{ proceeds?, disposalDate, disposalType?, notes? }`. Calculates policy + tax gain/loss, upserts `asset_period_ledger`, posts GL via `glCrossModuleHooks.postAssetDisposalToGL`. |
| `GET /api/accounting/assets/[assetId]/period-ledger` | `[assetId]/period-ledger.ts` | All `asset_period_ledger` rows for one asset ordered by period. Powers the dual-track Policy vs Tax tab on the asset detail page. |

## Auth

- `far-report.ts`, `far-report-xlsx.ts`, `deferred-tax.ts`, `[assetId]/period-ledger.ts`: `withAuth(withErrorHandler(handler))` — no CSRF.
- `below-threshold.ts`, `[assetId]/dispose.ts`: `withAuth(withCsrf(withErrorHandler(handler)))` — CSRF enforced on mutating methods.

## Response contract

All JSON routes use `apiResponse.success` / `.badRequest` / `.notFound`. `far-report-xlsx.ts` writes directly to `res` with `Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` — callers must NOT unwrap `json.data`.

## Business rules / gotchas

- `asAt` defaults to today if omitted. `period` for deferred-tax is `YYYYMM` (6 digits), not `YYYY-MM`.
- FAR uses `DISTINCT ON (asset_id) ORDER BY asset_id, yyyymm DESC` to get the latest period snapshot per asset.
- Disposal is idempotent at the `asset_period_ledger` level — uses `ON CONFLICT ... DO UPDATE`.
- `dispose.ts` blocks if asset `status = 'disposed'` already.
- Only `draft` PO edit analogue: disposal can run regardless of asset status except `disposed`.
- Services: `services/items/farDepreciationService.ts`, `farDisposalService.ts`, `farAfsService.ts`; GL hooks in `services/gl/glCrossModuleHooks.ts`.
