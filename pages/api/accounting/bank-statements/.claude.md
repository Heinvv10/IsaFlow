# bank-statements/ (PRD-05 Phase 7 — PDF import + dedup + commit)

Delegates to `bankStatementOcrService` (wraps pre-existing `vlmBankService.extractBankStatementWithVlm`).

## Endpoints
- `GET /api/accounting/bank-statements` — list imports with status + row/duplicate counts
- `POST /api/accounting/bank-statements` — multipart (formidable); body `{ bankAccountId }`; stores PDF via `storeCapturedBytes`, creates `captured_documents` row, runs extract+dedupe+persist to `bank_statement_imports` at `status='extracted'`
- `GET /api/accounting/bank-statements/[id]` — full import including `rows` (from `extraction_summary` JSONB) + warnings
- `POST /api/accounting/bank-statements/[id]/commit` — INSERTs non-duplicate rows into `bank_transactions` (`status='imported'`), flips import → `committed`
- `POST /api/accounting/bank-statements/[id]/rollback` — flips → `rolled_back`; no GL side-effects

## Auth
`withAuth(withErrorHandler(withWriteAccess(...)))` for POST routes; `withAuth(withErrorHandler(...))` for GET.

## Request / Response
`BankStatementImport`: `{id, companyId, bankAccountId, sourceDocumentId, periodStart, periodEnd, openingBalance, closingBalance, rowCount, importedCount, duplicateCount, status, rows[], warnings, createdAt, committedAt}`

`BankStatementRow`: `{date, description, reference, amount (signed), runningBalance, isDuplicate, duplicateOfBankTxId, duplicateMatchConfidence}`

## Business rules
- Dedup fingerprint: `lower(date|amount|desc[:30])`. Exact → confidence 1.0 + `isDuplicate=true`. Fuzzy: date ±1d + exact amount + description dice ≥ 0.7 → 0.9. Else not duplicate.
- Commit is all-or-nothing at SAVEPOINT level — individual row failures skip (`ON CONFLICT DO NOTHING` + null-date guard) without poisoning status flip
- Calling `/commit` twice → 400 `'Import already committed'` (test contract)
- `rolled_back` is terminal — no re-commit
