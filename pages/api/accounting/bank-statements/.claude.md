# bank-statements/

## Endpoints / Modules
PRD-05 Phase 7 bank statement PDF import + dedup + commit. Delegates to `bankStatementOcrService` (which wraps the existing `vlmBankService.extractBankStatementWithVlm`).

- `GET  /api/accounting/bank-statements` — list every import for the company, with status + row/duplicate counts.
- `POST /api/accounting/bank-statements` — multipart (formidable). Body includes `bankAccountId`. Stores the PDF via `storeCapturedBytes`, creates a captured_documents row, calls `createImportFromDocument` which extracts + dedupes + persists `bank_statement_imports` row at status='extracted'.
- `GET  /api/accounting/bank-statements/[id]` — full import detail with rows (from `extraction_summary` JSONB).
- `POST /api/accounting/bank-statements/[id]/commit` — INSERTs non-duplicate rows into `bank_transactions` as status='imported'. Flips status='committed'. Guards against already-committed + rolled-back.
- `POST /api/accounting/bank-statements/[id]/rollback` — status='rolled_back'. No DB rows inserted.

## Auth
`withAuth(withErrorHandler(withWriteAccess(handler)))` for mutating, `withAuth(withErrorHandler(handler))` for GET.

## Request / Response
BankStatementImport shape: `{id, companyId, bankAccountId, sourceDocumentId, periodStart, periodEnd, openingBalance, closingBalance, rowCount, importedCount, duplicateCount, status, rows: BankStatementRow[], warnings, createdAt, committedAt}`.
BankStatementRow: `{date, description, reference, amount (signed), runningBalance, isDuplicate, duplicateOfBankTxId, duplicateMatchConfidence}`.

## Business rules
- **Dedup fingerprint**: `lower(date|amount|desc[:30])`. Exact match → confidence 1.0 + isDuplicate. Fuzzy: same date ±1d + exact amount + description dice ≥0.7 → 0.9. Else not duplicate.
- **Commit is all-or-nothing at the SAVEPOINT level** — individual row failures skip (ON CONFLICT DO NOTHING + null-date guard) without poisoning the import status flip.
- **Already-committed throws**: calling `/commit` twice returns 400 with `'Import already committed'` (test contract).
- **Rolled-back state is terminal**: can't re-commit after rollback.
