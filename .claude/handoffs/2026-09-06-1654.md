- **`carriesLedger()` is safe by double entry** — the all-zero combination is unreachable for a company that has ever posted, because trading leaves accumulated result in `totalEquity` and any asset makes `totalAssets` non-zero. So "all zero" means "before the company existed", which is exactly the prior period that must be dropped.
- **`assertConsistent` has NO float tolerance, deliberately (R-P27).** Packs copy figures from services rather than computing them, so two readings of one source must be bit-identical; a float wobble means someone did arithmetic in a page, which is the defect the gate exists to catch. Do not add a tolerance.
- **A defect shape appeared FOUR times in WS4a**, three of them in code written to fix the previous instance: matching a pattern across a whole document instead of at the position where it carries meaning. It corrupted ledger labels, then a URL guard aborted renders on customer names, then two more checks had the same flaw, then the fix for those had it too. Closed by allow-listing what we emit rather than blacklisting what we fear. See memory `feedback_match_position_not_anywhere`.
